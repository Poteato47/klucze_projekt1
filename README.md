## PROJECT KEYS-STATE-TRACKER

The project's main goal is to create a device that tracks an arbitrary boolean value in real time by
updating an api and sending it to a github page.
Primarly, the code was expected to work with a button to track its state, but it is apparently possible
to use it for other purposes aswell.

## Installation
In order to apply the code, it is necessary to clone the contents of the repository into a folder.
Secondly, it is important to execute the following commands:
> sudo apt update
> sudo apt install libcurl4-openssl-dev -y
As the project was done in a remote Linux environment, these may need to be altered for other environments.
If you've done everything correctly, the program should work safe and sound. However, you may need to alter
the site's link/repo page if you want to apply it for other purpose or modify it for own needs.

## Usage
The site is very easy to use. Firstly, the program needs to be compiled. Then, it just needs activation
by running. 
> For now, the program uses just an oscillating value between 1 and 0 (true, false). Further alternation for
> devices required.
